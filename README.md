# Krillion Hints (krillionhints.com)

A high-performance SEO & GEO companion guide for the daily reverse-trivia game **Krillion** (`krillion.io`).

## 🚀 Key Features

- **Daily Dive 7-Prompt Clues**: Progressive hints, 7,000m deep sinker answers, and Too-Clever trap warnings.
- **Topical Authority SEO Cluster**:
  - `/how-to-dive-7000m/` (In-depth scoring strategy)
  - `/rare-answers-guide/` (Categorized high-depth vault)
  - `/what-is-krillion/` (Game background)
  - `/how-to-play-krillion/` (Rules & scoring breakdown)
  - `/krillion-vs-wordle/` (Comparison)
  - `/archive/` (Past prompts archive)
- **Deep Sea Trench Dark Aesthetic**: Responsive dark mode with neon cyan highlights.
- **Automated Daily Rebuild**: Scheduled GitHub Actions updating every 24h at 00:01 UTC.
- **Crawl Budget Optimization**: 45-day rolling indexation rule.

## 🛠️ Build & Deploy

```bash
npm install
npm run build
```
